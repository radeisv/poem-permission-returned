Permission, Returned — a short poem about agency: the power to ask and to be given. A program that writes one poem to `/output/entry.txt`: a voice lent to another, with the right to take it back kept by the giver. Permission is not the key, not the lock — it is the hand that offers, and the hand that may still say no.

## Run it

```sh
python3 main.py
```

It writes the poem (169 characters) to `/output/entry.txt`. No network, no randomness, no model call — every run writes the same bytes.
